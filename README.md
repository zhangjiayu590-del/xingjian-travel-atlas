# 行间 · 佳毓的旅行图集

一份经本人明确授权公开的个人旅行网站，围绕独自探索、普通人的日常、预算取舍和真实自由的纪实创作，规划下一段旅行。界面参考 [Awesome-Design-MD 的 Apple 设计分析](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/apple/DESIGN.md)，采用留白、摄影与编号索引。本站与 Apple 无关联。

公开源码：[zhangjiayu590-del/xingjian-travel-atlas](https://github.com/zhangjiayu590-del/xingjian-travel-atlas)。

公开网站：[行间 · 佳毓的旅行图集](https://zhangjiayu590-del.github.io/xingjian-travel-atlas/)（GitHub Pages 启用并部署完成后可访问）。

## 网站内容

- 18 个目的地、44 个官方资料入口，包含城市街区、海岛与自然观察路线。
- 每份攻略均包含推荐理由、分日路线、预算思路、纪录片拍摄题、出发限制及资料来源。
- 支持地名与兴趣搜索、主题筛选、收藏、3–14 天条件推荐、多目的地定制计划及文本导出。
- 较长停留在基础路线之外最多增加两个主题观察日，其余明确列为尚未安排的自由停留。
- 美国方向为未来愿望提案；已访国家的新路线不代表本人已到访所推荐的具体城市。

## 公开展示与本地数据

此代码仓库和由它发布的网站面向公众。页面所使用的姓名、已确认旅行经历、旅行与创作偏好、未来愿望，均已获得本人明确授权公开。相关内容来自截至 2026-10-20 的个人自述；未上传原始个人资料库、完整对话、家庭关系或其他无关材料。

每位访问者的收藏、筛选条件、行程、出发地备忘及清单，保存在当前浏览器的 `localStorage`。网站没有账户系统，不进行云端或跨设备同步，也不会将这些新增数据写回仓库。清理浏览器数据会删除本地记录，可先使用页面中的下载按钮导出 UTF-8 文本备份。

出发地仅用于备忘。路线是自主策划的参考提案，不包含实时订票、机票报价或签证判断；开放、交通和预约应以官方最新信息为准。资料核对日期为 2026-10-23。

## 本地运行

无需安装依赖，也无需构建。在仓库根目录运行：

```sh
python -m http.server 4173
```

然后在浏览器打开本地服务的 4173 端口。

## GitHub Pages

网站入口 `index.html`、脚本、样式和 `assets/` 均位于仓库根目录，资源使用相对路径，支持 GitHub Pages 项目站点。

1. 在仓库的 **Settings → Pages** 中选择 **Deploy from a branch**。
2. 选择网站文件所在分支及 **/(root)**，保存。
3. 等待 GitHub Pages 部署完成，使用设置页面显示的网址访问。

仓库根目录提供 `.nojekyll`。公开仓库不会让浏览器中的个人行程自动公开；页面展示的静态个性化内容则可以被所有访问者阅读。

## 文件

- `index.html`：页面结构与公开版说明。
- `atlas.js`：搜索、推荐、定制、收藏、本地保存与导出。
- `destinations.js`：18 份攻略、官方来源及图片署名数据。
- `styles.css`、`editorial.css`：基础样式与版式。
- `assets/`：18 张目的地图片及图标。
- `THIRD_PARTY_PHOTOS.md`：逐张照片的作者、源页、许可证与修改说明。
